# GitHub Repository Description

## Short Description (for GitHub "About" section — max 350 chars)

**ShelfBot** — Autonomous shelf-restocking robot simulation. ROS 2 Jazzy + Gazebo Harmonic workspace with FreeCAD-scripted 3D models (5-link kinematic chain), climb FSM controller, and shelf gap detection. PhD research project by Rohini Narayan Koli (Berlin).
